# Castillo Infinito

**Castillo Infinito** es un videojuego de terror y exploración en primera persona desarrollado con HTML, CSS y JavaScript, con escenarios tridimensionales creados mediante Three.js.

## Descripción

El jugador comienza en la puerta 300 y debe recorrer el castillo hasta llegar a la puerta 400. Durante el camino encontrará habitaciones, objetos que puede revisar, llaves, armarios para esconderse y peligros que deberá evitar. El objetivo es sobrevivir y escapar del castillo.

El juego incluye:
- Exploración en primera persona.
- Recorrido por las puertas numeradas del 300 al 400.
- Habitaciones y pasillos en 3D.
- Cofres, cajas y cajones que se pueden abrir.
- Llaves y objetos para recoger y utilizar desde el inventario.
- Linterna y barra de vida.
- Armarios donde esconderse.
- Enemigos, incluido el Guardián de Acero.
- Efectos de iluminación, sonidos y ambiente de terror.
- Menú de pausa y ajustes de sensibilidad de cámara.
- Controles para computadora y dispositivos táctiles.
- Pantalla de victoria y opción para volver a empezar.

## Objetivo

Avanza por todas las habitaciones, encuentra las llaves necesarias, recoge objetos útiles y evita a las criaturas del castillo. Si las luces tiemblan, busca un armario para esconderte. Si escuchas una armadura, corre o escóndete antes de que te encuentre. Para ganar, debes atravesar la puerta 400.

## Controles

### Computadora

| Tecla o control | Acción |
|---|---|
| W, A, S, D | Moverse |
| Ratón | Mirar alrededor |
| Shift | Agacharse (mantener pulsado) |
| E | Abrir puertas, cofres, cajas y cajones; recoger objetos y esconderse |
| F | Encender o apagar la linterna |
| M | Abrir o cerrar los ajustes |
| Espacio | Saltar |
| 1–6 | Usar el objeto del espacio correspondiente del inventario |

### Dispositivos táctiles

- Joystick en la mitad izquierda: moverse.
- Arrastrar en la mitad derecha: mirar alrededor.
- Botón **E**: interactuar con puertas y objetos, y esconderse.
- Botón de linterna: encender o apagar la linterna.
- Controles táctiles adicionales: saltar y agacharse.
- Botón de ajustes: cambiar la sensibilidad de la cámara.
- Toca un espacio del inventario para usar el objeto correspondiente.

En teléfonos, gira el dispositivo a posición horizontal para jugar.

## Requisitos

- Navegador moderno actualizado, como Google Chrome, Microsoft Edge o Firefox.
- Compatibilidad con WebGL y aceleración gráfica.
- Conexión a Internet para cargar las bibliotecas externas utilizadas por el juego.
- Teclado y ratón en computadora, o pantalla táctil en dispositivos compatibles.

## Tecnologías utilizadas

- **HTML5:** estructura del juego.
- **CSS3:** estilos, interfaz y controles.
- **JavaScript:** lógica, movimiento, interacciones y sistemas del juego.
- **Three.js:** representación de los escenarios tridimensionales.
- **Web Audio API:** reproducción y generación de sonidos, cuando está disponible en el navegador.

## Cómo ejecutar el juego

1. Descarga el archivo `index.html`.
2. Ábrelo con un navegador moderno.
3. Espera a que cargue y selecciona **ENTRAR AL CASTILLO**.
4. En computadora, haz clic en el juego para activar el control de cámara con el ratón, si el navegador lo solicita.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html` y `README.md` a la carpeta principal del repositorio.
3. Abre **Settings → Pages**.
4. En la configuración de publicación, selecciona la rama principal (`main`) y la carpeta raíz (`/root`).
5. Guarda los cambios y espera a que GitHub Pages publique el sitio.
